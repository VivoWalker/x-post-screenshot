# X 帖子截图

一个适用于 Chrome 和 Firefox 桌面版的 Manifest V3 扩展。按快捷键后选择 X/Twitter 帖子：普通帖子会把完整 PNG 写入剪贴板；Chrome 遇到含视频的帖子会录成小型 MP4，保存到下载目录的 `X-Post-Video` 子文件夹；Firefox 遇到视频帖则复制静态 PNG，不录制视频。其他 Firefox 内核浏览器可尝试 Firefox 版，但尚未逐一验证。

## Chrome 安装

先从 GitHub 仓库点击 **Code → Download ZIP** 并解压；Chrome 需要加载解压后的仓库文件夹，不能直接导入 ZIP。

1. 打开 `chrome://extensions`。
2. 开启右上角的“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择本目录。
4. 打开 X，按 `Alt+Shift+S`（macOS 为 `Command+Shift+S`）。

也可以点击浏览器工具栏中的扩展图标。快捷键可在 `chrome://extensions/shortcuts` 修改。

## Firefox 安装与使用

Firefox 版目前提供可临时加载的开发包。电脑需要安装 Node.js；在解压后的仓库目录执行 `node build-firefox.js`，生成 `dist/firefox` 文件夹。然后在 Firefox 地址栏打开 `about:debugging`，选择“此 Firefox”→“临时载入附加组件”，选择 `dist/firefox/manifest.json`。临时附加组件在浏览器重启后会失效；若要在正式版 Firefox 中长期安装，需要将扩展提交 Mozilla 签名，目前仓库不提供已签名的 XPI。

Firefox 版的快捷键和选帖操作与 Chrome 相同。长帖、多图和回复对话会按同一套识别逻辑截成 PNG 并直接复制到剪贴板。视频帖会截取当前显示的静态画面，不会生成 MP4，也不会下载 PNG 文件。由于开发环境未安装 Firefox，Firefox 浏览器中的最终效果仍需实测。

## 更改快捷键

右键点击浏览器工具栏中的扩展图标，选择“选项”，即可查看当前快捷键。点击“更改快捷键”会打开当前浏览器自己的扩展快捷键设置：Chrome 使用 `chrome://extensions/shortcuts`，Firefox 使用“管理扩展快捷键”。

## 使用

1. 将鼠标移到帖子上，被识别的帖子会出现蓝色边框。
2. 左键单击开始截取；按 `Esc` 取消。
3. 长内容会自动滚动和拼接，完成后恢复原来的页面位置。
4. 无视频时，两版都会将最终 PNG 写入系统剪贴板。视频帖在 Firefox 中也只会复制静态 PNG；在 Chrome 中，扩展会先暂停并重置到开头，再录制最多 30 秒。能明确识别主帖图片时，MP4 会采用「发帖人和文字 → 占满文字区域宽度的视频 → 主帖图片缩略图 → 互动信息」的排版；遇到引用帖或无法确定图片归属时，会保留整帖的原始截图布局，只在原视频位置叠加动态画面，避免把引用帖图片误排成缩略图或裁掉引用文字。配图不会在视频结束后轮播。MP4 下载完成时会在文件管理器中定位文件，按 `Ctrl+C` 复制该文件，再到聊天软件等目标处按 `Ctrl+V`。

Chrome 版视频先以完整帖子截图像素尺寸的一半为目标合成，并设 1440 × 2560、24 fps 的安全上限；目标视频码率约 8 Mbps、音频约 96 kbps，录制数据超过约 40 MB 时会停止。很长的帖子可能因画布高度上限进一步缩小；编码器的实际码率也可能与目标值略有不同。录制期间标签页音频会进入 MP4，但不经由扩展回放到扬声器；即使 X 播放器原先静音，也会为录制临时取消静音，结束后恢复原状态。若源视频本身没有音轨，扩展无法生成原声。

Chrome 版录制前会短暂显示两个彩色校准点，用于对齐浏览器录屏流和页面中的视频位置；校准完成后会移除，不会进入最终 MP4。若无法校准，或录制中视频位置发生变化，扩展会停止并提示重试，不会继续输出错位画面。

分段截图会自动控制速度；如果浏览器短暂拒绝截图，插件会等待并重试，因此很长的帖子可能需要多等几秒。

截图期间会暂时隐藏鼠标悬停触发的个人资料预览和提示浮层，保留帖子本身的作者信息；结束后页面恢复原状。

横向滚动的多图帖子会在截图时自动加载全部图片，并按原始顺序展开：两张图片并排、三张图片第一张全宽、四张及以上采用两列网格。帖子文字始终保持卡片完整宽度。截图时还会临时隐藏“有新帖子”等浮动提示，以及沉浸式翻译的悬浮按钮。

主帖只截取帖子本身。选择回复时，会截取当前 X 对话页中从主帖到所选回复的连续对话区域。为了让回复关系识别最可靠，建议先打开该回复自己的详情页，再启动截图。

## 当前边界

- MP4 文件无法由纯 Chrome 扩展直接作为 Windows 原生文件写入剪贴板；因此需要在文件管理器中手动按 `Ctrl+C`。缓存文件位于 Chrome 默认下载目录，不会自动清理。
- 如果 Chrome 当前环境不支持带音轨的 MP4 录制，扩展会报错，而不会输出伪装成 MP4 的其他格式。
- Firefox 版不录制视频；正式长期安装需要 Mozilla 签名，其他 Firefox 内核浏览器尚未逐一验证。
- X 如果尚未把更早的父级帖子加载进页面，扩展无法截取未加载的部分。
- 超过安全尺寸的截图会按比例缩小，最长边不超过 16000 像素且总像素不超过约一亿。
