# X 帖子视频录制实现计划

1. 保留现有 PNG 截图流程。只有所选帖子含视频时，先生成完整静态帖图，再切换为 MP4 录制。
2. 在内容脚本中暂停目标范围视频，保存原静音/音量/进度；将目标视频定位到起点并滚入视口。混合媒体须保留视频区域，同时展开图片。
3. 使用 Chrome tabCapture 在离屏文档取得音视频流。开始采集后才在页面内取消视频静音；Chrome 在标签采集期间默认抑制本机播放。画布以静态帖图为底，叠加实时视频；结束后顺序展示图片。
4. 采用受限画幅、帧率、码率和时长编码 MP4。保存到 Downloads/X-Post-Video，下载完成后在文件管理器定位，供用户手动复制文件。
5. 每条失败路径停止采集并恢复页面；增加针对混合媒体、限时、格式和下载流程的回归测试，打包新版本。

边界：源视频本身没有音轨时不能生成原声；Chrome 扩展不能直接把本地文件放入 Windows 原生文件剪贴板。
