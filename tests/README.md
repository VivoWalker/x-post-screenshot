# 验证截图与录制

在仓库根目录用 Node.js 22.13 或更新版本运行以下命令。单元测试使用 Node 自带的测试工具，Firefox 构建测试会创建临时目录并核对产物。

```sh
node --test tests/*.test.js
node build-firefox.js
```

浏览器测试需要 Python 3、Python Playwright、Chromium 和 ffprobe。运行 `python tests/browser_smoke.py`。若 Chromium 不在 PATH，可设置 `CHROMIUM` 为浏览器可执行文件的路径。

浏览器用例使用本地拦截的 X 页面、真实 Canvas、Async Clipboard、MediaRecorder 和音视频轨道。扩展消息通过测试适配器传递，录屏输入来自 Canvas 与 Web Audio。ffprobe 检查 MP4 中的两种流、输出尺寸与末端包时间差。Node 用例模拟标签页切换、后台消息、下载与编码异常。

## 桌面浏览器验收

| 场景 | 执行步骤 | 验收结果 |
| --- | --- | --- |
| 安装和选帖 | Chrome 加载根目录。Firefox 临时加载构建产物的 manifest。在选项页改键，通过快捷键和图标各选一次帖子 | 可以进入和退出选择，悬停高亮正常 |
| 剪贴板和拼接 | 选一条跨三屏、含文字和彩色图片的长帖，在 100%、125%、150% 缩放下截图并粘贴到图像编辑器 | 内容覆盖首尾，分段处文字连续，没有工具栏、提示或残留的高亮 |
| 切页与取消 | 先在剪贴板放入可识别文本。截长帖时切到另一标签页后立即切回。分别重复按 Esc、切换窗口、刷新和关闭原标签页 | 剪贴板仍是原文本。原页面如仍存在，应恢复滚动位置和图库。下一次截图成功 |
| 中断恢复 | 截取多图长帖或录制过程中终止扩展的后台 worker，再等待数秒并重新尝试 | 页面恢复，校准点消失，录屏指示结束，下一次截取成功 |
| 懒加载与回复 | 打开带引用帖的回复详情，选回复。对图库使用慢速网络并阻止一张可见图片，再恢复加载后重试 | 图片未齐时报错。重试的 PNG 包含预期主帖、回复及全部配图，引用卡片保留原布局 |
| Chrome 视频 | 各选一条短视频和一条超过 30 秒的视频。先调到中间位置，分别从静音播放及暂停状态录制。用有明显声画同步点的素材播放下载结果 | 保存到下载目录的 X-Post-Video 子目录。校准点不进入成片，音画对齐。长视频约 30 秒，页面恢复录制前的时间、音量和播放状态 |
| 音轨与下载异常 | 测试原本无声的素材，在可控制的环境中禁用标签页音轨，另一次在浏览器下载面板取消下载 | 无声素材保持无声，缺少标签页音轨时有错误提示。下载中断不会提示保存成功。后续任务可执行 |
| 录制中断 | 播放时移动视频、调整窗口、暂停或长时间阻塞视频加载 | 报错并停止录制，页面恢复。设备资源可供下一次录制使用 |
| Firefox 视频 | 临时加载 Firefox 包，选择原本正在播放的视频，再对暂停的视频重复一次 | 两次均可粘贴静态 PNG，音量和播放状态恢复 |
